# Doce Liberdade — site

Site da Doce Liberdade: doces e salgados sem glúten e sem lactose, com entrega no Plano Piloto, Brasília.

Site estático (HTML, CSS e JS puros), publicado pelo GitHub Pages.

- `index.html` — página única
- `style.css` — estilos
- `script.js` — menu, animações
- `img/` — fotos, logo e borboletas
